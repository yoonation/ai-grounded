# AI Grounded — brand assets

The mark is an electrical **earth-ground symbol** (a signal node dropped through a
descending foundation): *intelligence, anchored to a foundation.*

## Files
- `ai-grounded-logo.svg` — horizontal lockup, theme-adaptive (wordmark ink follows light/dark)
- `ai-grounded-logo-light.svg` / `-dark.svg` — fixed-ink lockups (for `<picture>` swaps)
- `ai-grounded-icon.svg` — icon / app tile
- `ai-grounded-icon-mono.svg` — single-color mark (stamps, embeds)
- `ai-grounded-social.svg` / `.png` — 1280x640 social / Open Graph card
- `ai-grounded-icon-{16..512}.png`, `favicon.ico` — raster icons
- `ai-grounded-logo-light.png` / `-dark.png` — raster lockups (Slack, decks, docs)

## Palette
| Role | Hex |
|---|---|
| Tile slate (gradient) | `#26324A` -> `#151E30` |
| Signal (node / "AI") | `#38BDF8` (on dark) / `#0EA5E9` (text on light) |
| Ground bars | `#EEF3F9` |
| Ink (wordmark) | `#0F172A` (light) / `#E7ECF3` (dark) |

## Type
Geometric grotesk, weight 700 — "AI" in the signal color, "Grounded" in ink.

## Do / don't
- Keep clear space around the mark of at least the height of the node.
- Don't recolor the tile, stretch the mark, or add effects.
- On busy photos, use the icon tile (self-contained) rather than the glyph-only mark.
