# Review checklist: release artifacts carry a valid SBOM

## Review questions

- Does every production release artifact have an associated SBOM in CycloneDX v1.6
  or SPDX v2.3 format, generated by the build platform from the build environment?
- Is the SBOM attached at the release surface the consumer uses (an OCI referrers
  attachment in the same registry, or the equivalent for the artifact type)?
- Is the SBOM generated from the build environment rather than hand-authored, so
  it reflects what actually shipped?
- Is generation wired into the pipeline so a new release cannot ship without one?

## Mechanical assist

An SBOM validator can confirm a present file conforms to the CycloneDX or SPDX
schema. That checks validity, not presence on every release; the coverage
property is review work.
