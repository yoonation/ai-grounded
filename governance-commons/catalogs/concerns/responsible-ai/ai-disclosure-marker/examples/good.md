# Example: responsible-ai.ai-disclosure-marker AI disclosure marker (good pattern)

Substrate-original illustration.

```python
# A shared response wrapper attaches the AI disclosure on every output path.
def ai_response(body: str) -> Response:
    return Response(
        content=body,
        meta={"ai_generated": True, "disclosure": "Generated by an AI assistant."},
    )
```

## Why this satisfies the rule

The user-facing output path attaches an AI-disclosure marker, and it does so on a
shared wrapper so the disclosure cannot be forgotten per endpoint. The person can
calibrate trust and seek a human alternative. Whether the disclosure is
prominent and clear is the responsible-ai.explanation-and-recourse review; this rule asserts a marker is
attached.
