# Guidance: Password storage uses an approved, computationally intensive password hashing function

Argon2id is the current substrate-recommended default for new applications. Substrate-recommended minimum parameters: memory 19 MiB, iterations 2, parallelism 1 (the OWASP Password Storage Cheat Sheet minimum as of the substrate version cited above). Tune so a single hash takes 250 to 500 milliseconds on production hardware; increase memory cost before iteration count. bcrypt is acceptable for existing applications and for legacy environments. Substrate-recommended minimum cost factor: 12. Note bcrypt truncates inputs at 72 bytes; if input length exceeds this and password length matters, prefer Argon2id. scrypt is acceptable when Argon2id is unavailable. Substrate-recommended minimum parameters: N equals 2 to the 17th, r equals 8, p equals 1. PBKDF2 is acceptable when FIPS-140 compliance is required. Substrate-recommended minimum iteration count for PBKDF2-HMAC-SHA-256: 600,000 (as of the substrate version cited above). All parameter recommendations require re-evaluation as attacker hardware improves. The substrate's profile tailoring mechanism allows organizations to encode stricter parameters than these minimums.
